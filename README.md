# майн+ — совместимый клиент Minecraft: Java Edition

Своя реализация клиента на современном коде: официальный набор функций и доступ
к мультиплееру, без поддержки модов. Цель — **Java Edition 26.3, протокол 777**.

Проект не связан с Mojang и Microsoft. Код игры и её ассеты не распространяются:
клиент читает их из установки игрока.

## Статус: в клиенте можно играть

Сделано:

- **E1 — Server List Ping**: handshake → status → ping/pong.
- **E2 — вход на сервер**: handshake → login → configuration → play, `Join Game` разобран.
- **E3 — мир**: `Chunk Data` → палитровые секции → блоки → ASCII-карта местности.
- **E4 — вход через Microsoft**: device-code вход, Xbox Live, Minecraft services, шифрование
  соединения (AES/CFB8) и подтверждение сессии. Ждёт одобрения приложения Mojang —
  см. [docs/auth-setup.md](docs/auth-setup.md).
- **E5 — картинка**: мир рендерится в PNG процессором (z-буфер) и в окне на видеокарте
  (OpenGL 3.3 через LWJGL, свободная камера). Текстуры берутся из установленной игры:
  1301 слой читается из `versions/26.3/26.3.jar` во время работы, ничего не распространяется.
- **Геймплей**: ходьба, прыжок, полёт, ломание и установка блоков, подсветка цели.
- **Мультиплеер**: клиент отправляет своё движение на 20 тиках (`Client Tick End` + пакеты
  позиции/поворота), поэтому другие игроки видят нас идущими, а сервер сохраняет нашу
  позицию между сеансами.
- **Сущности**: приём `Spawn Entity` / `Remove Entities`, интерполяция `move_entity_pos`
  и `entity_position_sync`; пока рисуются коробками.

## Сборка и запуск

Нужен **JDK 21** для сборки (проверено на Temurin 21.0.13). Gradle ставится сам через wrapper.

```
.\gradlew.bat build                          # компиляция + 45 тестов
.\gradlew.bat :app:run --args="mc.hypixel.net"   # список игроков
.\gradlew.bat :app:run --args="join"             # войти на сервер
.\gradlew.bat :app:run --args="world --chunks 5" # карта мира текстом
.\gradlew.bat :app:run --args="view --chunks 11" # мир картинкой в screenshots/world.png
.\gradlew.bat :app:run --args="window --chunks 11" # окно OpenGL: WASD, мышь, Esc
.\gradlew.bat :app:run --args="window --demo --hidden --frames 400" # самопроверка без рук
.\gradlew.bat :app:run --args="watch --seconds 20"  # что двигалось в мире за 20 секунд
```

## Сборка exe

```
.\gradlew.bat :app:packageExe
```

Результат — `dist\ultracraft\ultracraft.exe`: приложение с собственным рантаймом Java,
запускается без установленной Java. Внутри папки `dist\ultracraft` лежит всё нужное,
её можно переносить целиком.

```
dist\ultracraft\ultracraft.exe window           # окно: WASD, пробел, F — полёт, Esc — выход
dist\ultracraft\ultracraft.exe world            # карта текстом
dist\ultracraft\ultracraft.exe ping mc.hypixel.net
```

Если игра установлена в нестандартном месте, путь к ней задаётся явно:
`window --minecraft "D:\games\.minecraft"`.

## Локальный сервер (оракул протокола)

Ванильный сервер 26.3 — эталон, с которым сверяется клиент.

1. скачать `server.jar` для 26.3 с minecraft.net в `tools/server/`;
2. `.\tools\server-start.ps1`.

Скрипт сам создаёт `eula.txt` и `server.properties` (offline-mode, без whitelist),
находит JDK 25 и ждёт готовности. Каталог `tools/server/` в git не попадает.

**Важно:** сервер 26.3 требует **JDK 25**, а `white-list` у него по умолчанию включён.

## Вход через Microsoft (для online-серверов)

```powershell
$env:MCPLUS_CLIENT_ID = "<id приложения Azure>"
.\gradlew.bat :app:run --args="login"                      # один раз: код в браузере
.\gradlew.bat :app:run --args="world play.example.com --online"
```

Профиль и токены сохраняются в `.mcplus/account.json` (в git не попадает), повторный вход
не требуется. Требуется client id: [docs/auth-setup.md](docs/auth-setup.md).

## Таблица блоков

С 26.x реестр блоков — встроенный, по сети он не приходит: клиент обязан знать состояния
для своей версии. Таблица генерируется из официальных данных игры и в репозиторий не кладётся:

```
java -DbundlerMainClass=net.minecraft.data.Main -jar tools/server/server.jar --reports
node tools/build-block-table.js
```

Результат — `data/blocks-777.tsv` (1286 блоков, 35 723 состояния). Без него `world` не запустится
и подскажет эти две команды.

## Модули

| Модуль | Что внутри | Зависимости |
|---|---|---|
| `protocol` | VarInt, строки, UUID, позиции, NBT (сетевой), палитровые контейнеры, фрейминг с zlib | нет |
| `net` | соединение, ping, вход, реестры, разбор чанков, таблица блоков, мир, сущности, движение | `protocol` |
| `app` | CLI `mcplus` (`ping`, `join`, `world`, `view`, `window`, `watch`, `chunkdump`), физика, OpenGL | `net`, `auth` |

Правило слоёв: `protocol` не знает ни про мир, ни про сеть, ни про рендер.
