# ADR-0001: продукт — совместимый клиент

- Статус: принято
- Дата: 2026-11-18

## Контекст

Нужно переписать Minecraft на современном коде, сохранив официальные функции и доступ
к мультиплееру, без поддержки модов. Возможны три продукта: совместимый клиент,
совместимый сервер или headless-ядро протокола.

## Решение

Целевой продукт — **совместимый клиент** Java Edition, который заходит на официальные
и публичные серверы (протокол 777, версия 26.3). Ядро протокола разрабатывается как
отдельный слой (`protocol`, `net`) и не зависит от рендера.

## Следствия

- Нужны Microsoft-аутентификация, шифрование соединения и подпись чата — это обязательные
  требования online-mode серверов, а не опция.
- Нужен собственный воксельный рендер и загрузка ассетов из установки игрока.
- Первый этап (ping → login → join → чанк) полезен целиком: он одинаков для клиента и сервера,
  поэтому отказ от клиента позже не обнулит работу.
- Серверная часть не пишется: для игры достаточно официальных серверов.

## Отвергнутые варианты

- **Совместимый сервер** — быстрее до «играем вдвоём», но не отвечает на исходную жалобу
  на устаревший клиентский код и рендер.
- **Только ядро протокола** — не является игрой.
