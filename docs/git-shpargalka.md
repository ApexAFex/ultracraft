# Git с нуля — шпаргалка под этот проект

## Что такое git в двух словах

Git хранит **историю** папки. Ты работаешь как обычно, а иногда делаешь **коммит** —
снимок всех файлов с подписью «кто, когда, зачем». Любой снимок можно посмотреть,
сравнить с текущим состоянием или вернуться к нему.

Три слова, которых достаточно на старте:

- **репозиторий** — папка `C:\проекты\майн+` вместе с историей (история лежит в скрытой `.git/`);
- **коммит** — один снимок («добавил разбор чанков»);
- **ветка** `main` — линия коммитов, у тебя она одна, этого хватает.

Никакого интернета и аккаунтов. Всё локально.

---

## Шаг 1. Представиться (один раз навсегда)

```powershell
git config --global user.name "Твоё Имя"
git config --global user.email "твоя@почта"
```

Это подпись под коммитами. Никуда не отправляется, аккаунт не нужен, почта может быть любой —
даже `me@localhost`. Проверка:

```powershell
git config --global --list
```

## Шаг 2. Первый коммит

Перейди в папку проекта (в новом терминале git уже будет в PATH; если `git` не найден —
закрой и открой терминал заново):

```powershell
cd C:\проекты\майн+
git status              # что git видит: красным — новое, зелёным — готово к коммиту
git add -A              # «взять все изменения под контроль»
git commit -m "Каркас: протокол, Server List Ping, план"
git log --oneline       # history: должен появиться один коммит
```

Что произошло: `add` положил файлы в «корзину» будущего снимка, `commit` сделал снимок.
После этого `git status` скажет `nothing to commit, working tree clean`.

В первый коммит попадёт 12 объектов: `README.md`, `docs/`, `protocol/`, `net/`, `app/`,
файлы Gradle, `gradlew`/`gradlew.bat` и `gradle/wrapper/`. Каталоги `build/` и `.gradle/`
не попадут — они уже перечислены в `.gitignore`.

## Шаг 3. Ежедневный цикл — три команды

```powershell
git status                          # 1. что изменилось с прошлого снимка
git add -A                          # 2. подготовить всё
git commit -m "кратко: что сделал"  # 3. снимок
```

Правило: **один коммит — одна законченная мысль**. «Добавил VarInt и тесты» — да.
«Куча всего за неделю» — нет, такой коммит потом невозможно откатить.

Сообщения можно писать по-русски, это ни на что не влияет.

## Шаг 4. Посмотреть, что менял

```powershell
git diff                 # изменения, которые ещё НЕ в коммите
git log --oneline        # список коммитов, новые сверху
git show                 # что было в последнем коммите
git show <хеш>           # что было в конкретном (хеш из git log)
```

## Шаг 5. Отменить и вернуть

```powershell
git restore protocol/src/main/kotlin/mcplus/protocol/FrameCodec.kt   # выкинуть правки в файле
git restore .                                                        # выкинуть все правки, не попавшие в коммит
git revert <хеш>                                                     # отменить коммит, сохранив историю
git reset --hard <хеш>                                               # вернуться к состоянию коммита (стирает всё после него)
```

`restore` и `reset --hard` **необратимы** для несохранённых правок. Если сомневаешься —
сначала `git commit`, потом экспериментируй: так всегда можно вернуться.

Если что-то потерял: `git reflog` показывает все перемещения, даже «потерянные» коммиты,
и оттуда можно восстановиться.

## Шаг 6. Что в истории не нужно

`.gitignore` уже настроен — в историю не попадают `build/`, `.gradle/`, `.idea/`, `*.log`,
`tools/server/` (сюда позже ляжет ванильный сервер). Проверить, что игнорируется:

```powershell
git status --ignored
```

Если появился новый мусорный каталог — добавь строку в `.gitignore`.

## Шаг 7. GitHub — позже и по желанию

Локальный git не требует сети. Когда захочешь резервную копию вне компьютера:

1. создать пустой репозиторий на github.com;
2. `git remote add origin https://github.com/пользователь/репозиторий.git`
3. `git push -u origin main`

Дальше — `git push` для отправки, `git pull` для получения. Пока это не нужно.

## Если сломалось

- **`git status` почти всегда подсказывает следующий шаг** — читай его, а не гадай.
- `git` не найден → перезапусти терминал (PATH обновится).
- «Please tell me who you are» → не выполнен шаг 1.
- Хочешь мышкой → в VS Code есть панель Source Control: те же add/commit/push кнопками.
